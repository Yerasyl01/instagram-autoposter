# Instagram Autoposter

Automated Instagram advertisement poster that generates daily posts using AI image generation and language models.

## Architecture

The system follows the recommended architecture:

```
                    ┌─────────────────────┐
                    │ Advertisement data  │
                    │                     │
                    │ service             │
                    │ title               │
                    │ message             │
                    │ campaign settings   │
                    └──────────┬──────────┘
                               │
                 ┌─────────────┴─────────────┐
                 │                           │
                 ▼                           ▼
      ┌──────────────────┐        ┌─────────────────────┐
      │ Your fixed image │        │ Caption instructions│
      │ prompt template  │        │                     │
      └────────┬─────────┘        └──────────┬──────────┘
               │                             │
               ▼                             ▼
      ┌──────────────────┐        ┌─────────────────────┐
      │ Meta Muse        │        │ Ling 3.0 Flash Fin  │
      │ via OpenRouter   │        │ via OpenRouter      │
      └────────┬─────────┘        └──────────┬──────────┘
               │                             │
               ▼                             ▼
          Instagram image              Instagram caption
               │
               ▼
      ┌──────────────────┐
      │ instagrapi       │
      │                  │
      └────────┬─────────┘
               │
               ▼
           Posted!
```

## Prerequisites

1. Python 3.8+ installed
2. Instagram account credentials with business/verification enabled
3. OpenRouter API key (get from https://openrouter.ai)
4. Reference advertisement image (see next section)

## Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure environment variables:**
   Create a `.env` file in the project root:
   ```
   OPENROUTER_API_KEY=your_openrouter_api_key_here
   SESSION_ID=sessionId_from_cookie
   ```

3. **Authorize user**
   Put in .env SESSION_ID. It will allow for Instagram authorization by sessionId.
   You can find session ID by downloading Cookie-Editor extension in browser and logging in into Instagram.

4. **Create reference image:**
   Run the reference image generator:
   ```bash
   python scripts/create_reference_image.py
   ```
   
   This will generate a sample advertisement showing the visual style. Review it carefully - all future posts should match this design system.

5. **Review and adjust:**
   If the reference image needs changes, modify the `create_reference_image.py` script and regenerate.

## Usage

### One-time test run
Test the full workflow without actually posting:
```bash
python main.py --test
```

### Dry run (see prompts only)
See what prompts would be sent without generating content:
```bash
python main.py --dry-run
```

### Post a specific service
Post a specific service by ID (1-6):
```bash
python main.py --service-id 3
```

## How It Works

1. **Service Selection**: Automatically selects a service based on the current date (rotates daily)

2. **Image Prompt Generation**: Builds a fixed template prompt with service-specific variables

3. **Image Generation**: Sends prompt to Meta Muse via OpenRouter (includes reference image for consistency)

4. **Caption Generation**: Sends caption prompt to Ling 3.0 Flash Fin via OpenRouter

5. **Instagram Posting**: Uploads image and caption to Instagram using instagrapi

6. **Daily Schedule**: Can run automatically at a set time each day

## Technical Notes

- **No prompt generation model needed**: The image prompt template is fixed, only variables change
- **Consistent branding**: Reference image ensures all posts match the same visual style
- **Reliable text**: Phone number and address are added to reference image, not generated by AI
- **Session persistence**: Instagram session is saved to avoid re-login each day

## Troubleshooting

**Login fails:**
- Check credentials in `.env` file
- Ensure Instagram account is verified
- Use `scripts/create_session.py` for new `session.json`

**Image generation fails:**
- Verify OpenRouter API key is valid
- Check if reference image exists
- Review logs in `logs/autoposter-*.log`

**Post scheduled daily:**
- Check `scheduler.log` for any issues
- Ensure script is running (use `cron` or Windows Task Scheduler for persistent execution)

## Customization

To modify the advertisement style:
1. Edit the prompt templates in `config.py`:
   - `get_image_prompt()` - controls image generation
   - `get_caption_prompt()` - controls caption generation

To add new services:
1. Add new service dictionary to `SERVICES` list in `config.py`
2. Update `ALL_SERVICES` list for general ads
